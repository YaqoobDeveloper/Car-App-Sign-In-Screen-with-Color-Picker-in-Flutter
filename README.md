# Car-Dealership-Sign-In-Screen-UI-in-Flutter

A clean, modern car dealership sign-in screen built with Flutter. No third-party packages.

## Project structure

```
lib/
├── main.dart
├── app.dart
├── core/theme/app_theme.dart
├── screens/login_screen.dart
└── widgets/
    ├── car_illustration.dart
    ├── social_button.dart
    └── remember_me.dart
```

## Run

```bash
flutter pub get
flutter run
```
