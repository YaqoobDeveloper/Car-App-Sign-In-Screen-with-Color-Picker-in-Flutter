# Car App Sign-In Screen with Color Picker in Flutter 🚗🎨

A modern and clean **car app sign-in screen UI** built with Flutter, featuring a customizable car color picker.

This project focuses on a polished automotive-themed authentication experience with a clean layout, interactive color selection, reusable widgets, and responsive design.

## ✨ Features

- 🚗 Modern car app sign-in UI
- 🎨 Interactive car color picker
- 🔐 Email and password sign-in fields
- 👤 Remember me option
- 🔵 Social sign-in buttons
- 🧩 Reusable Flutter widgets
- 📱 Responsive layout
- ⚡ Lightweight and fast UI
- 🎯 Clean and organized project structure

## 🛠️ Built With

- **Flutter 3.47.2**
- **Dart**

## 📋 Requirements

- Flutter **3.47.2** or compatible version
- Dart SDK included with Flutter
- Android Studio or VS Code
- Xcode for iOS development

## ▶️ Run

### 1. Clone the repository

```bash
git clone https://github.com/YaqoobDeveloper/Car-App-Sign-In-Screen-with-Color-Picker-in-Flutter.git
```

### 2. Navigate to the project

```bash
cd Car-App-Sign-In-Screen-with-Color-Picker-in-Flutter
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the app

```bash
flutter run
```
